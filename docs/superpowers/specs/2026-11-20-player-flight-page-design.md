# 飞入时先不显示播放页

## 目标

飞入播放页和返回时，圆角框还在动，画面上只留这个框。框落地后，播放页底色、画面黑底、控制条和竖屏下半部分的剧集信息同一帧出现。

## 页面

要不要藏这些层，收成 `hidePlayerPageForTransition(transitionActive)`。过渡进行中返回 `true`。`transitionActive` 来自 `playerTransitionActive()`。没有共享范围时当作没在过渡。

返回 `true` 时：

- 播放页根上不铺主题底色
- 竖屏画面区的两层黑底不铺。控制条、上下遮罩、片头片尾、拖动和双击的进度预览、亮度、音量和倍速提示不组合
- 竖屏下半部分留一个权重 `0.62` 的空位，剧集信息不组合。画面区保持权重 `0.38`，圆角框仍飞向这块画面
- 横屏两层黑底不铺。横屏控制条和同样的提示不组合。画面框仍是整页
- 投屏按钮和投屏小条不组合
- 倍速、更多和投屏设备这些弹层不组合。弹层原来的打开状态留着，过渡结束后按原来的条件再出现

圆角目标框继续组合。视频表面仍只走 `hidePlayerSurfaceForTransition`。已经选用 TextureView 的，表面在飞行全程仍然显示。画中画那个分支不经过这个判断。投屏的视频表面保持现在的样子。

过渡结束、判断变成 `false` 的那一帧，这些层按原来的条件组合。控制条的淡入淡出留着。这一次是带着已经可见第一次组合，所以不播进入动画。返回时判断变成 `true`，这些层当帧离开组合。`controlsVisible` 不改。

换集不走导航过渡，这些层保持。没有匹配的缩略图时，共享过渡不进行，播放页按现在的方式出现。

## 测试

单元测试覆盖两种：

- 过渡中：隐藏
- 未过渡：显示

不使用 Compose 界面测试或 Robolectric。

## 这一轮不动

- `hidePlayerSurfaceForTransition` 和设置里的表面类型
- 圆角、共享 key 和哪一张缩略图注册
- 导航的淡入淡出时长
- 共享边界的框弹簧
- 缩略图的加载和占位规则
- 画中画和投屏的现有画面
- 控制条自己的显示计时
- 竖屏 `0.38` / `0.62` 的比例
- 播放决定和下载
