# 按剧记住音轨、字幕和倍速

## 目标

同一部剧下次打开、或换到另一集时，沿用上次选的音轨语言、字幕选择和倍速。片头片尾继续用现有的 `SeriesSkipStore`。这份记忆用同一个 `seriesKey`，存在新的存储里。

没有 `seriesKey` 的单集不记。单集倍速仍写入设置里的默认倍速。

## 存储

新建 `SeriesPlaybackStore`，DataStore 名 `series_playback`。

- `spa:` + `seriesKey`：音轨语言。缺省表示自动。
- `spt:` + `seriesKey`：字幕。缺省表示自动；固定记号 `__off__` 表示关闭；其他值是语言代码。
- `sps:` + `seriesKey`：倍速，限制在 `0.5f..5.0f`。缺省表示用设置里的默认倍速。

`seriesKey` 为空时，读取得到空设置，写入直接返回。

字幕存储值的读取：

- 缺省：自动
- `__off__`：关闭
- 去掉首尾空白后为空，或忽略大小写等于 `und`：自动
- 其余原文：该语言

```kotlin
data class SeriesPlaybackSettings(
    val audioLanguage: String? = null,
    val text: SeriesTextMemory? = null,
    val speed: Float? = null,
)

sealed interface SeriesTextMemory {
    data class Language(val code: String) : SeriesTextMemory
    data object Off : SeriesTextMemory
}
```

## 选择怎么记

语言代码去掉首尾空白后还是空的，或者忽略大小写等于 `und`，就不能跨集记住。能记住的代码按去掉首尾空白后的原文保存。

音轨：

- 自动：清掉这部剧的音轨记忆。
- 有可用语言：记下这个代码，当前文件立刻用这条轨道。
- 没有可用语言：只作用在当前文件，已有记忆保持不变。

字幕：

- 自动：清掉这部剧的字幕记忆。
- 关闭：记下关闭。
- 有可用语言：记下这个代码，当前文件立刻用这条轨道。
- 没有可用语言：只作用在当前文件，已有记忆保持不变。

视频轨只改当前播放，不写入。

同一集里有多条相同语言时，当前这次选择用现在的轨道序号命中用户点的那一条。换集或下次打开只按语言选，由播放器在该语言里自己挑。

用户这次点选写入记忆后，当前这一集保持刚才的序号选择。轨道列表随后刷新不再套用剧集记忆。套用发生在：打开当前这一集并且轨道已经出来、换到另一集并且轨道已经出来、记忆变成另一套值并且不是这次点选刚写入的那一套。套用过一次之后，同一集、同一套记忆不再套用。

套用时清掉音轨和字幕的序号覆盖，再按记忆设置偏好语言或关闭字幕。视频轨的现有覆盖留在播放器上。离开播放页时用来关掉画面的视频轨开关也不改。

这一集没有记下的语言时，回到自动。

## 外挂字幕

手动选择优先于同名外挂。记成关闭时不挂同名外挂；这一集上手动选的文件仍然挂上，并且不改剧的记忆。记成某种语言时，有手动文件或同名外挂就用那个文件，没有才按语言选内嵌字幕。

`PlaybackSession.resolveSubtitle` 改为使用这个结果。关闭状态由界面在剧集记忆变化时传给会话。已经挂上的同名外挂不从媒体项上拆掉；关闭指令会关掉字幕轨，画面上不显示。

有外挂字幕要显示时，内嵌字幕的语言偏好让给这个文件：字幕轨保持开启，并清掉字幕偏好语言。

## 倍速

这部剧有自己的倍速就用它，否则用设置里的默认倍速。播放器里的倍速弹层：有 `seriesKey` 时只写这部剧，并更新当前播放速度；没有时仍写默认倍速。

长按加速的那一档不写入。加速过程中，默认倍速或剧集倍速到达，都不改当前这一档。松开后回到加速前的速度。

设置页只改默认倍速。这部剧已经有自己的倍速时，改默认值不影响它。剧里一旦改过倍速，就保持那个数，直到在播放器里再改。这一轮没有“跟随默认倍速”的开关。

打开播放页时可以先用已经在手里的默认倍速，剧集倍速一到就换上。

## 接入位置

- 新建 `app/src/main/java/com/pfpt/localvideoplayer/data/SeriesPlaybackStore.kt`
- 新建 `app/src/main/java/com/pfpt/localvideoplayer/player/SeriesPlaybackLogic.kt`，放纯函数
- `PlayerOverlaySheets.kt`：倍速弹层和音轨、字幕弹层在有 `seriesKey` 时写新存储
- `PlayerScreen.kt`：现有“默认倍速盖掉当前速度”的效果改为使用剧集倍速或默认倍速
- 换集和记忆变化时套用轨道偏好，放在播放器现有的会话效果里
- `PlaybackSession.kt`：解析外挂字幕时看关闭状态
- 设置页不改
- 投屏不读这份记忆，起播保持现在的路径

## 测试

只测纯函数，不写 Compose 或 Robolectric。文件：`app/src/test/java/com/pfpt/localvideoplayer/player/SeriesPlaybackLogicTest.kt`

- 空语言和 `und` 不能记；普通语言代码能记
- 音轨自动会清除记忆；无语言的选择保持原记忆
- 字幕自动会清除；关闭会记下；无语言的选择保持原记忆
- 字幕存储里的 `__off__` 读成关闭；`und` 和空白读成自动
- 有剧集倍速用剧集值；没有则用默认倍速
- 长按加速时，新的有效倍速不改速度快照
- 有手动字幕就用手动文件；关闭且没有手动文件时不挂同名外挂；有语言且只有同名外挂时用该文件
- 有外挂字幕时，内嵌字幕选择让给这个文件；关闭且没有外挂时关掉字幕轨；只有语言时按语言选内嵌字幕
- 轨道还没出来时不套用；同一套记忆套用过一次后不再套用；点选刚写入的那一套不套用

## 这一轮不动

- 片头片尾的存储和界面
- 字幕字号、颜色、延迟
- 视频轨的跨集记忆
- 长按加速的速度计算
- 设置页的默认倍速入口
- 投屏起播
- 飞入动画、片库、下载
